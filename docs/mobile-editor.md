# 移动端编辑与验收范围

本页记录开发阶段的已实现行为，不代表最终签名 APK 或公开发行已完成。

## 操作方式

- 首页提供餐厅400㎡、办公300㎡、健身房1000㎡、40客房酒店、零售200㎡五类独立场景。酒店展示四个真实楼层，不把整栋面积当作当前层。
- 默认进入平面图。底部切换平面图、全项目报价、全项目拓扑；拓扑中的设备可返回对应楼层和同一设备标识。
- 点击房间或空白只用于浏览，不会添加设备。添加需先选择明确工具；单指平移、双指缩放，拖动设备必须先在属性中启用。
- 图标避让使用显示坐标与细引线，工程坐标不变。拖动按手势增量计算，不能把引线偏移误算为安装点移动。
- AP、半球监控、机柜、宽带入口及关联线路默认显示。有线网口及支线放在“网口图层”中；隐藏不改变点位数量、线材或报价。
- 共线路段按蓝橙交替显示。点击/键盘选中可查看参与电缆、移动并锁定关联线路；可显式解锁后再修改。独立电缆仍分别计量。
- “全屏画布”使用安卓沉浸式系统栏控制，保留退出与保存。系统返回键先退出沉浸，再关闭面板、返回平面图或项目列表。
- 需求、数量、无线代际和单价草稿必须应用才进入工程。未处理草稿会阻止切换；撤销/重做以一次完整应用为单位，包含其线路重算。
- 可选设备展开不计价；“购买”或“已有仅联网”均需明确加入。正在修改单价时，先应用/取消，再编辑其他单价或加入备选设备。
- 宽带入户点的X/Y是图纸坐标，单位米，不是价格、带宽或端口号。

## 保存与恢复

安卓使用原生私有项目文件，已应用编辑自动保存，可主动重试。当前项目入口采用同步提交的私有导航记录，避免把 WebView localStorage 的延迟落盘当作进程死亡保护。导入下一层前等待保存确认，将真实保存版本传入新界面。

浏览器只用于开发，项目存入当前来源的 localStorage；不模拟原生OCR、文件选择器或安卓原子存储。原生导入后的识图校正仍由原有校正界面完成，新增楼层走同一规划与路由引擎。

## 验证证据

自动测试覆盖五场景、酒店逐层、未应用草稿、锁定减量拒绝、拖动与撤销、显式添加、共用路段再编辑、Wi-Fi5/6改价、备选加入移除、包干人工改价、三视图一致、页面重载和横屏画布占用。

原生检查脚本：

- `scripts/android-planner-smoke.mjs`：真实安装包五场景、酒店第4层、系统栏隐藏/返回、报价/拓扑、强制停止进程后锁定点位恢复。
- `scripts/android-layout-smoke.mjs`：真实 Android WebView 双指手势、工程坐标不变、手机横屏和平板尺寸；结束恢复该测试设备的原始显示设置。
- `scripts/android-storage-smoke.mjs`：保存版本冲突和跨进程数据恢复。

测试机是 AOSP Android API36 ARM64 模拟器，不是实体手机。屏幕截图使用自制演示场景，不含客户图纸。

仍须在最终发行阶段重跑首次安装离线OCR、导入/导出文件闭环、完整PDF、签名安装及公开Release下载校验。不能把本阶段界面检查当作这些步骤已完成。

系统栏实现参考：[Android 官方沉浸模式](https://developer.android.com/develop/ui/views/layout/immersive)。
