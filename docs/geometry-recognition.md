# 图形识别与校正边界

输入是原生渲染后的实际RGBA像素和真实OCR文字框，文件名和场景标签不参与识别。文字识别与几何识别是两条独立管线；没有封闭区域时返回明确缺失信息，不套用模板。

本地图形线程将最长边缩至最多1200px，灰度阈值二值化、屏蔽文字框、单像素闭运算、提取封闭白色连通区域、跟踪像素边界并简化多边形。保留斜边和凹角。候选房间按文字框的空间归属命名和推断用途，始终待人工确认。房间最多100个，超出提示裁切或人工校正。

这不是通用建筑图理解模型。彩色底纹、双墙线、家具封闭线框、未识出的文字、开口墙线和低分辨率会产生多余、合并或缺失的候选。墙线是内侧像素轮廓，可能成对出现；不能直接当作建筑墙体中心线。多房间的建筑边界初值是候选包络，凹形外边界须人工重画。门洞不在证据不足时自动猜测。

用户可在原图叠加层绘制/修改建筑边界和房间顶点、补删墙线、改名称/用途/Wi-Fi需求、逐房确认、添加门或通道并指定连接房间及宽度、标机柜/宽带入口/监控目标。门必须靠近其连接房间边界；隐私用途不能保留监控目标。重叠、自交、未确认房间及无效引用阻止应用。

标尺优先两个已知端点与实际米数；面积法明确标为近似。标尺缺失不产生伪精确米数或完整施工报价。草稿门宽单位是`widthPx`，确认转换后才成为`widthM`；原图与原始PDF附件身份均保留，不保存临时文件URI。

长任务在Worker运行；取消终止线程，旧任务不能覆盖新结果或清除新任务忙碌状态。重新识别需确认，只替换未应用候选，不写入既有项目。完整项目持久化由后续项目模块负责，本阶段校正页面不声称已落盘。

## 已验证证据范围

- 纯像素合成输入：双房间、L形凹空间、斜向双房间带噪点，以及空白/只有文字框的图。测试资产为项目原创，非客户图纸。
- 真实Worker浏览器校正：修改隐私用途、确认墙线、标记机柜/入户、应用长度标尺，手机390px宽度无页面横向溢出。
- Android离线链路：系统选择原始四房间测试PNG→随包OCR→本地Worker→四个可校正房间；不是浏览器模拟OCR。
- 原图叠加实际检查修复了斜角重叠标签，房间使用内部编号，对应下方完整编辑卡片。编号是显示标记，不改变工程锚点。

上述证据不等同于任意真实客户图纸可自动完成施工设计。最终APK验收将再次检查导入、校正、布点、保存与导出的完整链路。
