## 实际完成度

可用离线原型：React/TypeScript + Capacitor Android；有导入、人工校正、五类场景、点位布线、联动报价/拓扑、本地保存及 SVG/PNG/CSV/PDF/工程包。预算价格和覆盖能力为估算；复杂图纸不能直接施工。历史验收数字见 acceptance.md，本轮测试不能代替历史设备或实体手机认证。

尚不存在联网多租户产品：没有后端、数据库、登录、密码哈希、会话、租户成员、租户管理员或对象鉴权。Android 原子文件保存仅有应用沙箱保护；浏览器开发模式使用 localStorage，同一浏览器配置共享数据，不是用户/租户隔离。不得直接将本地存储桥接暴露为公网接口。没有可审查的密码哈希/会话实现，也不能称这些安全检查已经通过。

## 识别与呈现链路

系统选择 PNG/JPEG/PDF → LocalDocumentsPlugin 限额及 PDF 栅格化 → 随包 ML Kit 中文/拉丁模型 OfflineTextRecognizer → 图像 Worker 阈值/墙线/封闭区域候选 → RecognitionPage 人工确认房间、用途、门、标尺与机柜 → 业务工程 schema → 确定性规划与 SVG/React 页面。没有 DeepSeek 请求、API 密钥或云识图；Android manifest 移除 INTERNET，自动备份关闭。SVG 文本有 XML 转义，导出原图只接受内嵌 PNG/JPEG，React 普通文本渲染不执行模型脚本。

[DeepSeek 官方视觉文档](https://api-docs.deepseek.com/guides/vision/) 当前支持 deepseek-flash 图文输入；不能沿用“只有文本模型”的旧结论。模型能力及 ID 需部署时重新核验；OCR-2 是另一条自部署开放权重路线，不把它当成官方托管 API 名称。

推荐服务器 → 可配置视觉适配器 → 限额/超时/失败处理 → 严格业务 JSON schema 校验 → 人工修正 → 现有确定性 SVG/HTML。JSON mode 不等于几何正确，必须拒绝空/截断/非法坐标/越界引用，保留原图及来源。细小文字需对合成工程图做整图与裁切效果比较，记录文字、房间/门召回率、隐私区域错误及延时成本，不能只看漂亮图。

不执行任意模型生成 HTML/SVG/JS；不从模型返回 URL 自动抓取文件。只让模型提交受限数据，经模板呈现。密钥仅在服务端，显式获得图片外传许可并设保留/删除策略；本轮没有调用模型或发送用户图片。

## 本轮独立缺陷

ImportPage 的 page/rotation 改变没有失效已有识别结果，导致“选第2页/转90度”仍可把上一次页面送进校正。合成桥接的真实 React 页面回归先证明两种控制均失败，再修复改变页码/旋转时清空旧结果与旧错误；重试识别开始也清空旧结果。桥接样本只测试 UI 状态，不冒充实际 Android OCR 结果。旧发布 APK 仍有此缺陷，需经验证后重新签名发布修正版。

## 大改选项与准入条件

1. 推荐保留离线版，另增后端 API、网页管理台和可选同步客户端；支持无网络工作，原图上传按项目授权。
2. 将现有应用改为联网产品：需要网络权限、登录/离线缓存隔离、同步冲突策略、隐私声明变更，范围和回归成本更大。
3. 本轮止于独立修复和架构评估，后续再批准服务器化实施。

服务端设计必须以服务端验证的身份和租户成员关系为准，不能信任客户端 tenantId、隐藏按钮或猜不到的 UUID。项目/图纸附件/识别任务/输出/导出下载均绑定租户和项目；每次读写验证成员资格及对象权限。数据库启用租户条件和 PostgreSQL RLS 等第二层防护；后台管理员权限与普通租户管理员分开、显式授权并记录审计。

密码使用经过维护的 Argon2id 实现和独立随机盐，参数按服务器实测配置；不使用明文/可逆加密/直接 SHA256。会话使用高熵随机 token、数据库仅保存摘要、撤销/过期、登录限速；网页 Cookie 设 Secure/HttpOnly/SameSite 并防 CSRF。服务端凭据和云模型密钥不发给网页/APP、不写入 Git。

对象存储默认私有、下载前鉴权或短期签名链接，队列任务在服务端再次校验租户，删除/日志/备份/导出也覆盖隔离。上线门槛测试：租户 A 的身份对租户 B 项目、附件、任务、输出、删除、导出全拒绝；普通成员不能提升为后台管理员；会话过期/撤销立即失效，日志没有图纸和凭据。需要新基础设施及实测，不能声称本轮已实现这些要求。

本轮不部署、不合并、不改可见性、不创建凭据，不改动本机签名材料。复验结果和 draft PR 以最终工作报告为准。
