# 合成场景与几何约定

五个场景均为本项目原创的合成演示图，不是客户施工图。面积是室内轮廓面积，不另扣隔墙厚度。房间矩形完全铺满各自轮廓、互不正面积重叠；门洞是显式房间连接，不按房间名称临时猜测。全部坐标以米保存。墙体暂按轻隔墙，现场材质必须复核。

这些数值是可修改的场景输入，不代表行业标准。无线并发指同时使用无线网络的终端数，允许一人多终端；总终端是全网络计划终端数，包含无线和有线，不再叠加员工/顾客人数。有线信息点是固定物理端口数，不再叠加进总终端作为双倍需求。后续加入经营终端时按实际联网方式明确增量。酒店全楼面积1600㎡，每层设备与路径独立计算。

## 隐私与监控目标

房间用途在数据层声明：客房、卫生间、更衣与淋浴为隐私区域；会议室、独立办公室默认不安装监控。模板只提供监控目标，不预先放置AP/摄像头，实际点位须经过与上传图相同的规划引擎。入口、收银、公共流线与经营区使用明确目标坐标。图标避让不能改变这些工程坐标。

## 几何验证范围

单元测试覆盖面积、凹多边形点包含、边界、线段交叉/共线/相切、墙体与已确认门洞、刚性变换，以及五类场景的房间范围/门洞引用/目标合法性。米坐标随旋转平移一致变换，原图标定的像素原点与角度同步更新。

几何预览于390×844及1024×900浏览器视口生成、逐图检查；仅是场景数据验收，不是安卓界面验收。手机全图缩略时标签较小，正式编辑器必须支持缩放和设备/标签避让，不把此预览当作交付界面。
