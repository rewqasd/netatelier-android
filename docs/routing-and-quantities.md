# 路径、共线显示与独立工程量

每根设备电缆保存独立ID、真实机柜/设备端点、米制折线路径、锁定和施工确认状态。平面图上的蓝橙交替线段只合并显示，不合并电气身份。线段仅在同层、共线且确实重叠的长度范围内共享；相交一点不算共享，逆向走线仍正确合并。

路由通过已确认房间、门/通道和用户线槽建立图，采用随房间旋转的直角折线，先走机柜与门洞主干，再分支到设备。不会在密闭房间之间生成貌似已确认的穿墙直线。用户明确画出的线槽若穿墙，保留暂估路径并提示确认。导入图双墙内轮廓允许已确认门洞跨越每侧最多0.25m的墙厚偏移；不确认的门不会放行。

新墙、端点变化或建筑边界变化会使不再有效的锁定线路转为待确认/断开，但不擅自重画其受保护路径。共享段移动作为一次楼层事务同步改动所有参与电缆，保留实际设备端点；任何参与线路锁定则整次拒绝。过大的路由图限制到700节点/30000房间内候选边组合，返回阻断提示，不无界搜索。

## 算量口径

- 净网线：每根有效独立电缆折线长度之和。相同10m路由的两根网线计20m。
- 网线采购基础：`(净长度 + 每根 × (两端各自预留 + 一次引下)) × (1 + 余量率)`。配置中的“端点预留”是每一端的米数，“引下”是每根合计米数。
- 唯一线槽：物理路径几何并集。上述两根共用10m路由，只计10m线槽。计算保留原始坐标；汇总至毫米精度，避免旋转时因提前坐标舍入破坏共线关系。
- 跨层主干：单独保存三维路径和介质，不把首层长度复制到其他楼层。光纤/铜缆主干不混入水平网线净量字段，采购与端接由报价模块按介质另算。
- 共用竖井：各根主干独立计长度，重叠竖向线槽只计一次。0→3m和0→6m两根光纤计9m光纤、6m竖井线槽。
- 超过90m的铜缆固定链路（含两端预留及引下）、未连通、路径待确认、缺少标尺或楼层主干，均产生阻断问题。界面可展示已知部分，但不能称为完整施工报价。

全楼自动宽带入口只在首层保留；人工指定的其他入口不会被删除。酒店默认生成首层机柜至各层机柜的光纤星形主干，竖井按首层机柜坐标假设，必须确认实际楼高、平面坐标对齐和竖井后才标为已确认。移动机柜后，报价检查真实三维端点，不能继续使用旧主干冒充有效路线。

箱装网线如何裁切、采购剩余和按米采购互斥由下一阶段报价模块负责，不把净线长直接当成整箱采购数量。

验证包含：反向/局部重叠、旋转/平移、交叉不合并、跨层不混并、共享拖动保端点、锁定解锁、封闭房间、导入墙厚门洞、改变墙体后的锁定路径、酒店主干、独立线/唯一槽/余量手算。算法检查图已检查餐厅厨房共干分支、办公区和酒店首层；这些不是最终移动UI的验收截图。
