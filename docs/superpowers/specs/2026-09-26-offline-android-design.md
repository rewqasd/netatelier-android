# 组网工坊（NetAtelier）独立离线安卓应用设计

日期：2026-09-26

状态：本文件保留实施前批准的设计要求；当前实现与验证结果见 [验收记录](../../acceptance.md)，不以本设计描述替代完成证据。

## 1. 已确认的目标

用户明确放弃 Linux 产物，要求在本机从零生成独立离线 APK，并推送到自己的公开 GitHub 新仓库，供安装、验证和再次构建。

- 不依赖 Linux、SSH、Tailscale、电脑上的开发服务或远程识图 API。
- 不复制或继续修改“集优·智策”旧项目。
- 核心闭环为：导入平面图 → 本地识别及人工校正 → 点位与布线图 → 报价 → 独立网络拓扑 → 保存及导出。
- 提供至少五类能真正打开、修改和保存的典型场景。
- 经营硬件只作可选推荐，未主动加入不影响总价或网络需求。
- 交付可安装的 APK、公开源码、安装与构建说明及可核查的测试证据。

暂定应用名“组网工坊”，工程名 `netatelier-android`，包名 `io.github.rewqasd.netatelier`，公开目标 `rewqasd/netatelier-android`。截至本次检查，该仓库尚不存在，GitHub CLI 当前身份为 `rewqasd`。创建前再次校验，若出现同名仓库，不覆盖它。

这是初步勘察与预算工具，不是现场射频实测、安防施工审签或正式成交承诺。

## 2. 技术路线及取舍

采用 **React + TypeScript + 本地 SVG 画布 + Capacitor Android + 原生识图/文件插件**。

- 所有界面、字体、图标、计算规则、五类模板及默认设备目录随 APK 打包，无远程首页、CDN 或运行时脚本下载。
- 安卓原生层负责系统文件选择、PDF 页面渲染、内置 OCR、项目文件读写、导出分享及打印。
- TypeScript 纯计算模块负责图纸几何、候选房间、设备布点、路由、算量、价格和拓扑；与 UI 分离，可独立测试。
- 手机是主要产品。浏览器只用于开发、快速检查和计算测试，不把浏览器通过当作原生识图及文件功能通过。
- 不做单纯加载远程网站的 WebView 外壳。

与全 Kotlin 原生相比，该路线更便于实现复杂 SVG 编辑和复用同一计算模型；与远程后台相比，它没有服务保活和连接要求。代价是需要维护一层明确的原生桥接，并在 Android WebView 上验证触控、内存和生命周期。

目标最低 Android 8.0（API 26），覆盖 ARM64 手机和 ARM64 模拟器；其他架构仅在实测后列入支持范围。锁定兼容的 Capacitor、Gradle、JDK、SDK 与 npm 依赖，构建工具缺失时在实施阶段安装，不直接沿用本机 Java 25 假设兼容。

## 3. 离线、权限与数据边界

首次安装后，即使断网、关闭 Wi-Fi 和移动数据，也必须能打开五类场景、导入本地图片/PDF、OCR、校正、生成方案、修改、保存和导出。

- OCR 采用 ML Kit 随应用打包的中文及拉丁文字模型，不采用首次使用时经 Google Play Services 下载模型的方式。
- 不申请通讯录、位置或全盘文件访问权限；用 Android 系统文档选择器取得用户选择的文件。
- 不上传图纸，不接入统计、广告或远程日志服务；审核合并后的权限清单，移除核心功能不需要的网络权限和分析组件。第三方库的隐私条件须在依赖说明中记录，不凭“本地模型”声称不存在任何库级遥测。
- 外部商品来源由用户点击后交给系统浏览器；没有网络时，应用仍可使用随包目录和人工单价，不偷偷联网刷新。
- 项目和导入文件复制到应用私有存储；导出通过系统选择位置或分享入口进行。
- 不依靠云备份实现保存；禁用项目图纸的自动云备份，用户自行导出备份。
- 导入文件限制大小、像素和 PDF 页数，提供明确错误；异常文件不得造成无限加载或应用崩溃。
- 项目删除需确认；不得连带删除用户原始文件。

## 4. 用户流程与五类场景

首页直接提供“导入平面图”“选择场景”“我的项目”，不设 CRM、营销页面或强制账号登录。

| 场景 | 默认规模 | 必须体现的不同空间 |
| --- | --- | --- |
| 餐厅 | 400㎡ | 入口、候餐、收银、就餐、包间、厨房、库房、卫生间 |
| 办公企业 | 300㎡ | 前台、开放办公、会议室、独立办公室、公共通道、弱电位置 |
| 健身房 | 1000㎡ | 前台、有氧、力量、团操、瑜伽、设备间、更衣、淋浴、卫生间 |
| 酒店 | 40客房，4层，每层约400㎡ | 每层10客房、走廊、交通核，首层大厅/前台及弱电位置 |
| 零售门店 | 200㎡ | 入口、收银、货架、主通道、仓储及员工区 |

模板数据明确标为演示假设，房间范围不重叠、尺寸与标定面积一致；酒店全楼1600㎡不冒充单层面积。各场景员工、顾客/住客、在线人数、终端、带宽及监控参数均可修改；展示推导依据，防止人数和终端重复累计。

模板必须走与上传校正后相同的计算管线，不能给模板使用一套“漂亮截图”专用算法。

生成后进入大画布。底部切换平面图、报价、拓扑；需求和选中对象属性用可收起面板。手机支持横屏，平板使用更宽布局；不以桌面页面整体缩小代替移动适配。

## 5. 真实导入、识别与校正

导入 PNG/JPEG 或 PDF；PDF 显示页数并明确选择页面，可逐页建立楼层，不默认把全部页面当作同一张图。修正图片旋转信息，合理缩采样，保持识别坐标与原图的变换关系。

识别分三部分：

1. 原生 OCR 返回文字及边界，不编造识别百分比。
2. 本地图像处理进行二值化、线段/连通区域提取，生成墙线和房间候选；门洞仅在证据足够时标为候选，其余待确认。
3. 用识别文字与几何关系推断房间用途、入口候选及隐私区；所有推断允许校正并标明来源。

长耗时处理在后台线程或 Web Worker 中进行，有阶段进度、取消和失败状态。取消/失败不覆盖已保存的原项目。

校正能力必须包括：建筑边界、房间范围/名称/用途、门或通道连接、机柜、宽带入口、监控目标、已知长度标尺。保留原图叠加显示，可以重新识别到候选草稿而不覆盖已确认结果。

比例策略：优先两个标记点加已知米数；只有面积时可选择近似缩放并明确假设；无有效比例时不提供伪精确工程米数，不将施工总额标为完整。

未形成足够可信房间或通路时，明确显示缺失条件并引导校正。不能根据图片文件名、房间数量或场景标签偷偷替换成内置模板。

## 6. 唯一项目数据与编辑事务

保存结构带版本号，包含：项目全局需求、楼层、原图引用、坐标变换/标尺、房间多边形、墙线、门/通道、监控目标、点位、独立电缆路径、选型、价格覆盖、已加入经营设备、手工锁定状态。

平面图、报价、拓扑均从同一份已应用项目生成。页面上的配置草稿不进入总价和保存状态；应用形成一次历史事务，支持撤销/重做。切换楼层或项目前处理未应用草稿。

保存采用临时文件写入后原子替换，并保留最近有效版本以应对中断。大图独立存储，不把 base64 图像反复塞进历史栈。应用切后台、旋转屏幕、系统重建后恢复项目；不默认删除项目或重生成点位。

导入项目时校验结构版本、数值范围、楼层引用、压缩文件路径与附件大小。未知版本不可静默丢字段。照片和项目数据不进入 Git。

## 7. 点位引擎

### 7.1 AP

基于真实比例、房间用途、需要服务的区域、墙体假设、并发与终端需求、安装形态生成候选；采用可解释的覆盖/容量与冗余权衡，不按屏幕像素均匀撒点。

Wi-Fi 5/6 对应实际候选型号、安装形态、接口及功率；型号变化不改已有物理坐标。显式数量不足时保留用户选择并提示容量/服务区域缺口，不假装满足要求。

每台 AP 可查看服务区域与理由。覆盖显示为简化规划示意，不是现场射频热力测量；近邻、墙体未知和容量不足分别提示。合理隔墙相邻不简单判为错误，不能以“有墙”就断言完全无干扰。

### 7.2 摄像头

依次建立监控目标、合法安装候选、简化视线/遮挡关系，再选择覆盖目标的点位。目标包括入口、收银、公共通道和明确需要监控的公共经营区。

- 严格排除客房、卫生间、更衣、淋浴等隐私区；会议室和独立办公室默认不安装。
- 默认半球图标，保留目标和视向数据，选中才显示简化视域。
- 不默认全朝同一方向、不默认全部朝门、不按页面底部或数组顺序集中布置。
- 遇到墙体遮挡、无合法候选、数量上限不足时，列明未覆盖目标。
- 镜头、高度、现场遮挡未知时标注视域限制，不宣称真实安防覆盖率。
- 旋转/平移图纸后，安装合法性和目标覆盖应保持等价；对对称空间的等价候选不要求像素完全一致，但不能出现固定朝屏幕下方的偏置。

### 7.3 手工编辑

选中后显式进入拖动/添加工具，普通点击房间或导航不添加设备。单指平移与设备拖动有明确状态，双指缩放，提供适应画布、撤销、重做与沉浸式全屏。

锁定点位不被自动重算删除。减量低于锁定数时拒绝应用并解释。新增或移动后重新核算关联路线；若不能找到合法路线，标记未连通，不能保留旧长度冒充新线路。

显示图标和标签可避让，但真实锚点固定，用细引线区分，且不得裁出可见画布；不修改工程坐标来修复视觉重叠。

## 8. 路径、共线显示与工程量

每个楼层建立可通行/可敷设的路由图，由门、通道、弱电位置和用户指定线槽组成。按实际障碍寻找路径；穿墙或未证实可施工位置必须标为待确认。多楼层采用明确的机柜和主干关系，不直接复制首层线路长度。

共享路径只在渲染层合并；保存的每根设备电缆仍独立。共线段蓝橙交替，分叉后分别连接，点选显示线数和终点。多线共享段移动时同步更新参与路径但不漂移设备端点。

算量区分净路由、两端预留、引下、余量、独立电缆、唯一线槽/桥架、跨层链路。共用槽不重复计量，独立线不因合并显示而漏计。箱装采购与按米采购互斥，连续长线裁切和采购余料可解释；链路超限、路径不连通或标尺缺失使报价标为不完整。

## 9. 离线目录、报价和可选硬件

默认计入实际必要的网关/路由器、AC能力、AP、交换机/PoE及上联、已启用监控的摄像头与录像存储、必要配线和机柜、线材辅材、基础施工测试。AC已集成则不重复收费；关闭监控时不保留其设备/存储及相关工程费用。

配套校验包括：网关接口/规划终端能力、AP管理兼容性及数量、每台交换机端口/上联/单口和总PoE、NVR通道/吞吐/硬盘位、存储容量与保留天数。未知规格必须标未知，不把带宽等同于带机量。

设备目录随包携带查询快照，不依赖实时访问电商才能使用。实施阶段核对中国大陆电商精确型号、商品来源、日期、页面价格和条件；无法核实的项明确暂估。不得把二手、套餐或其他型号最低价用作新机单价。施工费率单独列出，并允许用户修改。币种人民币，整数分计算，项目合计与逐行一致。

金额分必要网络、监控、材料、施工、已加入可选项。原单价、人工采用价及恢复操作清晰。数量、型号、无线代际、保留天数变动时重新核算所有配套；不直接编辑一份与点位脱节的BOM数量表。

前台电脑、POS、厨房打印机、扫码、门禁、考勤及非必需UPS/服务放在独立可展开推荐区。草稿和展开操作无费用/端口增量。只有“加入方案”才应用；支持“购买设备”和“已有设备仅联网”，后者只增加必要联网工程。移除可逆、不误删无关手工点位。

## 10. 独立拓扑与导出

拓扑表达宽带入口→网关→核心/楼层/接入交换机→AP、摄像头、已加入终端，正确表示AC及NVR。只有真实使用NVR PoE口时才画摄像头接NVR；不虚构端口号、VLAN和速率。分楼层分组，点选节点可定位回平面图，数量与分配取自同一工程计算结果。

支持：

- 含原图和项目数据的导出/导入文件，用于换手机或手工备份；
- 平面图、拓扑的独立SVG及清晰PNG；
- 报价CSV（正确转义并防止公式注入）；
- 中文可读的多页PDF方案：逐层图、拓扑、报价、来源及待确认项。

采用本地渲染与系统文件/打印能力，不访问云端转换。明确导出范围和成功文件位置；取消导出不修改工程。PDF禁止漏楼层、切断报价行或遗漏未确认风险。

## 11. 安卓构建、签名及公开发布

本机补齐安卓SDK、兼容JDK和模拟器，构建APK后实际安装验证。当前没有连接实体安卓手机，因此先用ARM64模拟器；实体机兼容性留给用户验收，不能声称已在用户手机实测。

验证版提供可安装签名APK、SHA-256校验值、版本号与对应提交。签名密钥仅保存在本机仓库外，不进入GitHub；明确告知备份位置及丢失密钥影响后续覆盖升级。不要借用未知来源签名或公开私钥。此次不做应用商店上架。

公开仓库包含源码、依赖锁定、Gradle wrapper、构建说明、测试、合法演示资产和简要证据。排除密钥、凭据、客户图纸、项目数据、个人机器路径、开发日志中的私人信息及未审查的旧仓库历史；在全新仓库发布，不公开旧项目。

发布前检查依赖许可、敏感内容和体积。没有用户指定时不擅自给其全部源码另加开源许可证，第三方许可证仍必须保留。创建公开新仓库并推送后，发布验证版Release，附APK和校验值；重新下载检查一致性。不使用商店、不部署任何运行后台。自动构建工作流不读取私人签名密钥，产物标清用途，不将CI临时签名包混称可覆盖安装的发布包。

## 12. 验收矩阵与完成标准

| 项目 | 必须看到的证据 |
| --- | --- |
| 五类场景 | 手机上逐一打开，参数修改后图纸/报价/拓扑一致，酒店逐层可用 |
| 首次离线运行 | 全新安装后关闭网络，未预下载模型仍完成导入/OCR/校正/生成/保存/导出 |
| 真实识图 | 至少3种非模板截图输入，覆盖清晰、文字尺寸、低质量/旋转；标明来源并检查识别与校正结果 |
| 识图真实性 | 不读文件名/测试答案套模板，真实OCR结果有文字边界；低质量允许明确失败但校正闭环可用 |
| 摄像头 | 公共监控目标被解释，隐私排除，遮挡/缺口提示，旋转和平移无屏幕底部偏置 |
| AP | 按比例和业务区域布点，人数/容量/距离警告真实，Wi-Fi5/6对应型号和功率变化 |
| 布线 | 两根独立线共用槽的手算样例、分叉、共享段编辑、余量一次、跨层与超长警告 |
| 报价 | 整数分合计、配套校验、可选项默认零增量、已有设备不收硬件费、加入/移除可逆 |
| 手工编辑 | 拖动/锁定/应用/取消/撤销/重做，生成不覆盖受保护编辑 |
| 持久化 | 保存重启、切后台、旋转和项目文件往返后坐标/数量/附图保持 |
| 安卓UI | 手机竖横屏与平板布局，系统返回键、沉浸式退出、弹层、无手势误加设备 |
| 导出 | 本地PDF逐层及报价核对，SVG/PNG/CSV/项目包实际保存并重新打开 |
| 构建和安装 | 本机构建命令退出0，签名验证通过，APK安装启动并执行核心流，无致命崩溃 |
| GitHub交付 | 公开仓库存在且提交一致，Release可下载，下载APK哈希与已验证产物一致 |

测试分纯计算单元测试、原生插件测试、Web交互测试和Android端到端检查。不要用浏览器模拟OCR成功替代安卓OCR，不用后端/单元测试数量替代实际图纸和APK验收。为金额、工程量、旋转及隐私规则使用独立期望值，不能调用被测算法生成答案。

测试图若为自行制作，明确标记，不冒充真实客户图纸。通过截图实际检查标签、点位、图例、共线分叉和价格，不能只检查DOM或节点数。未满足的条目记录为未完成，不通过删除断言、缩减功能或改写验收标准来宣称交付。
