# 安装、使用和备份

1. 从本项目正式Release获取APK和SHA-256；发布前测试包不是正式交付。
2. 最低Android8.0/API26，已测环境以验收记录为准。实体机、厂商打印服务及旧WebView尚需实测。
3. 允许文件管理器/浏览器安装此次APK，之后可撤销该来源权限。不同签名不能覆盖安装；卸载前先备份。
4. 无需电脑端口、服务器或账户，断网选择模板或导入本地PNG/JPEG/PDF。
5. 核对房间、墙线、门洞、机柜和比例，填写需求，检查三种视图与待确认事项。
6. 估算单价须当地核实；经营设备仅在主动加入后计费或增加联网需求。

点位属性中的“解锁关联线路并重算”会保留当前已应用坐标，并取消未应用的位置草稿。线路锁定时不能直接移动端点。摄像头使用半球符号；选定公共监控目标后应用，只改变规划视向，不改变安装位置。酒店机柜移位后的跨层主干需要再次核查确认。

## 文件与恢复

完整工程包`.netatelier`包括原图、规范化图片及可编辑数据，适合换手机；恢复为新项目，不覆盖同名旧项目。SVG/PNG/CSV/PDF不能替代工程包。

PDF使用系统“保存为PDF”。返回应用不代表一定保存成功；请到系统文件管理器实际打开检查。取消或错误提示不能当作完成。

私有数据在卸载/清除应用后丢失，请另存重要工程包。发布者须备份仓库外签名私钥和密码，丢失会影响同一应用的覆盖升级；私钥不含在APK、仓库或Release中。
