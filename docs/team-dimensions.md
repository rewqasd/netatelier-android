# Dimensions in the private team workbench

New vision requests retain the exact uploaded pixel canvas. Linear labels carry their original value/text, mm/m/unknown unit, kind, endpoints, confidence, source, optional chain ID and human confirmation. This is schema validation, not proof of image recognition accuracy. Old drafts are preserved; old normalized coordinates must be verified against the original before setting a scale. An unknown unit is never assumed to be mm.

The drawing unit selector applies only to the current drawing/request; choosing a file resets it to unknown. The new recognition source metadata records the requested unit. Migration gives old source rows unknown and does not modify existing projects or image contents.

Import `examples/dimension-candidates.json` only into a synthetic 100×100 coordinate draft. It appends local candidates after confirmation and does not invoke a model, overwrite geometry, save, or set a confirmed scale. The synthetic top chain is 4000+6000mm=10m. Unknown-unit and elevation entries cannot calibrate area; furniture is not a room span. Applying a planar dimension creates an unconfirmed scale; independently verify endpoints, evidence and metres before checking the scale confirmation and explicitly saving. An area scales by the square of metres per coordinate unit; mm² to m² divides by 1,000,000. Dimension chain totals are annotations, never automatically accepted scales or areas.

Functional zone polygons, furniture and physical walls have different meanings. Optional room `boundary` distinguishes functional/physical/unknown. Optional `openings` store door gap endpoints, evidence, confidence, confirmation and zero-based room indices. The UI can create a door candidate from an opening dimension, associate rooms (displayed from 1), confirm or delete it. Deleting a room remaps door references and withdraws door confirmation. Missing/unconfirmed references or a continuous wall across a gap block planning. Physical walls must be corrected independently; deleting an erroneous candidate only changes local state until explicit save.

Existing network plans remain proposals requiring a site survey. The boundary is still a room-envelope rectangle. Actual building/net areas, elevation units, wall materials, RF performance and model fidelity are not established by these tests. This change was tested with synthetic images and mocked provider responses only; it makes no additional paid model calls.
