# 本地项目与便携项目包

项目数据存放于应用私有目录；图库/系统文件选择器提供的原文件不被修改。图片和PDF为独立文件，项目只持有随机附件标识，不把原图base64放进编辑历史。项目文件只有唯一工程数据，不保存另一份独立BOM。

## 保存与恢复

- 每次保存携带预期版本；版本不同明确返回冲突，不覆盖较新内容。前端保存队列串行提交同一项目的快速修改，并采用已确认版本。
- 项目正文封装SHA-256校验值，临时文件写完并同步后原子替换；目录同步。保留一份最近有效版本。
- 中断留下的临时文件不会被当作项目。最新文件损坏/校验不符时读取已校验备份并恢复；无有效备份时保留损坏项目条目，不能默默当作空项目。
- 删除需要明确确认，只删除该项目的私有JSON及其备份。共享附件暂不自动垃圾回收，避免误删另一个项目或未保存草稿；它们占用应用空间，清除应用数据或卸载会移除。先导出需要保留的项目包。
- Android `allowBackup=false`，不把图纸交给自动云备份。换设备使用项目包。

## `.netatelier` 格式1

ZIP包含 `manifest.json`、`project.json` 和清单列明的 `assets/<随机标识>`。清单记录每个附件的大小与SHA-256；项目的原图与标准化栅格都要包括。解包采用原生流式复制，不向WebView传大文件base64。

限制：项目正文2MiB、附件单个50MiB、全部展开内容128MiB、最多256条目、项目最多20层；图片尺寸还受导入安全限制。目录项、绝对路径、反斜线、越界路径、重复条目、未声明附件、丢失引用、散列错误和未知版本会拒绝。大小上限在实际解压流中执行，不相信ZIP头声明值。

导入先进入私有暂存区，检查附件内容及原生结构边界，再在前端用完整项目Schema校验。通过后才发布为新的项目ID和新附件ID；即使来源项目ID相同，也不覆盖原项目。失败/取消不修改已存工程。已导出的项目包包含原图，不加密；分享前自行确认其中没有不应披露的平面图或业务信息。

项目包导出通过Android系统保存位置选择器；取消不改工程。若写入目标位置途中失败，明确告知该位置可能有不完整文件，不假报导出成功。SVG/PNG/CSV/PDF由独立导出模块实现，不与项目备份格式混用。

## 已验证边界

原生测试使用自制平面图文件验证实际字节往返、全新私有存储导入、校验/版本/路径/解压上限以及最近有效版本恢复；另通过真实Android进程强制停止与重开，验证原生桥保存的点位、锁定、单价和版本冲突。完整项目界面自动保存、横竖屏和系统选择器操作仍须在整机UI验收阶段验证，不能用这些存储测试替代。
