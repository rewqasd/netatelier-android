# 点位规划规则与限制

点位使用米制几何，不读取页面高度或按画布底部排序。候选网格的轴来自房间边，随图纸一起旋转。AP与摄像头分别计算，不为排版移动物理锚点。

## AP

先按需要无线服务的房间生成采样点，再以墙体折减后的等效距离、未服务点数和设备间距选择候选。内部阈值为8.5m等效距离；轻隔墙/玻璃/砖/混凝土/未知墙分别加入2.5/2/5/9/6m等效距离。这些是本软件的保守规划参数，不是材料的真实射频衰减测量或厂商承诺。

Wi-Fi6/5当前以40/25个活跃终端每AP作容量规划假设，取同时在线人数与60%终端数两者较大值，避免直接相加重复计算。实际选型规格由设备目录另行校验，不能把该假设写成产品最大带机量。未知墙材、容量缺口、未服务采样点均产生明确提示。最小新增AP候选间距2.5m；室内墙体和业务需求可能要求相邻独立区域分别安装，不能仅凭两个覆盖圆重叠判断故障。

用户数量及型号变化不会擅自删除受保护点位；仅改变无线代际不改变位置。手动移动会清空旧服务声明和相关线路，重新检查后才能使用新的工程量。

## 摄像头

输入是明确监控目标，再生成合法房间的近墙候选，以目标权重、视线和视角增益选点。简化假设14m视距、90°视角；真实镜头、安装高度和遮挡未勘察，始终有风险提示。门洞视为几何可见开口，开关门状态需另行核实。

客房、卫生间、更衣、淋浴不安装；会议室及独立办公室默认排除。未覆盖目标单列，不虚构完成率。已有违法/失效的受保护点位不悄悄删除，而是保留并阻断提示。普通图层使用半球标志；内部保留目标ID和朝向供选中检查、导出和后续校验。

## 事务和计算边界

所有应用操作克隆输入，验证结构与引用后才产生新项目。配置草稿不进入该模型。移动、加入可选项、修改参数分别是一条历史事务；撤销/重做保留最近50次，图像本体不进入历史。显式删除设备同步留下数量选择，后续自动规划不将它复活。可选硬件仅主动加入后生成带来源ID的终端端口；移除只删除关联端口。

单层规划最多100房间/4096房间顶点，另限制候选与墙线组合工作量。过大输入返回阻断问题，要求拆分区域，不启动无界搜索。项目文件仍可保存，不能把“跳过计算”显示为完整方案。

算法检查图覆盖五类场景及旋转餐厅。当前默认生成结果为餐厅5AP/3摄像头、办公4AP/2摄像头、健身8AP/4摄像头、酒店首层6AP/3摄像头、零售3AP/3摄像头。这些是给定合成房间和需求下的算法结果，不是按面积背诵的行业标准或最终施工配置。
