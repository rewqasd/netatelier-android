# 离线与数据边界

- 应用无INTERNET或ACCESS_NETWORK_STATE权限，不依赖服务器、CDN、广告或账号。
- ML Kit中文/拉丁模型随包。第三方SDK可能包含遥测相关实现；不能声称SDK本身绝无此类代码。应用网络权限限制仍适用。
- 系统文档选择器只读取用户选定文件；原件复制到私有目录，用户源文件不变。50MiB文件、24MP图片、60页PDF上限；识别栅格最长边2400px。
- 原子保存并保留最近有效备份，禁用Android自动备份。卸载/清除数据会丢失本机项目，请先导出完整工程包。
- 删除项目只移除记录及项目备份。避免破坏共用原图，附件暂不自动回收，可能留下占用空间的孤立附件。
- 导出文件由用户及目标应用管理；分享须用户选择接收方，不自动发送。
- 用户点击商品链接后才交给系统浏览器，不后台更新价格或上传图纸。
- Debug包可能有插件诊断日志，仅使用合成测试图；正式包须检查非调试配置。不要上传客户图纸或原始日志。

输出不代替现场射频、工程勘察、监控隐私审查或采购合同。第三方原文可在首页“隐私与第三方声明”断网读取。
